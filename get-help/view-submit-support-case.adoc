= Envoi et consultation des dossiers de demande de support pour les systèmes de stockage ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Si vous rencontrez un problème nécessitant une assistance, utilisez ONTAP System Manager pour soumettre une demande d'assistance technique ou pour consulter les demandes clôturées ou en cours.

Vous devez être link:https://docs.netapp.com/us-en/active-iq/task_login_activeiq.html["Enregistré auprès de Active IQ"^] pour consulter les demandes d'assistance concernant votre système ASA r2.

.Étapes
. Pour soumettre une demande d'assistance, dans System Manager, sélectionnez *Cluster > Support* ; puis sélectionnez *Accéder à NetApp Support*.
. Pour consulter un dossier précédemment soumis, dans System Manager, sélectionnez *Cluster > Support*, puis sélectionnez *Afficher mes dossiers*.
