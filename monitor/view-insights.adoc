= Optimisez la sécurité et les performances de votre cluster avec les Insights système ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Consultez _Insights_ dans ONTAP System Manager pour identifier les meilleures pratiques et les modifications de configuration que vous pouvez implémenter sur votre système ASA r2 afin d'optimiser la sécurité et les performances du cluster.

Par exemple, supposons que vous ayez configuré des serveurs NTP (Network Time Protocol) pour votre cluster. Toutefois, vous ignorez que vous disposez de moins que le nombre recommandé de serveurs NTP nécessaires pour une gestion optimale de l'heure du cluster. Pour vous aider à prévenir les problèmes pouvant survenir lorsque l'heure du cluster est imprécise, Insights vous avertit que vous avez trop peu de serveurs NTP configurés et vous propose des options pour en savoir plus sur le problème, le résoudre ou l'ignorer.

image:insights.png["capture d'écran de la page d'informations system manager"]

.Étapes
. Dans System Manager, sélectionnez *Insights*.
. Examinez les recommandations.


.Et la suite
Exécutez toutes les actions nécessaires pour mettre en œuvre les meilleures pratiques et optimiser la sécurité et les performances de votre cluster.
