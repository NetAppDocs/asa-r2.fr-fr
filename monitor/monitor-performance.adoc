= Surveillance des performances du cluster et de l'unité de stockage sur les systèmes de stockage ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Utilisez ONTAP System Manager pour surveiller les performances globales de votre cluster et de vos unités de stockage spécifiques, notamment la latence, les IOPS et le débit, sur des périodes allant d'une heure à un an.

Par exemple, supposons qu'une application critique subisse une latence élevée et un faible débit. En consultant les performances du cluster sur les cinq derniers jours ouvrables, vous constatez une baisse de performance à la même heure chaque jour. Cette information vous permet de déterminer que l'application critique entre en concurrence pour les ressources du cluster lorsqu'un processus non critique commence à s'exécuter en arrière-plan. Vous pouvez alors modifier votre politique QoS afin de limiter l'impact du workload non critique sur les ressources système et de garantir que votre workload critique atteigne les objectifs de débit minimum.



[[monitor-cluster-performance]]
== Contrôle des performances du cluster

Utilisez les metrics de performance du cluster pour déterminer si vous devez déplacer des charges de travail afin de minimiser la latence et d'optimiser les IOPS et le débit pour vos applications stratégiques.

.Étapes
. Dans System Manager, sélectionnez *Dashboard*.
. Sous *Performance*, affichez la latence, les IOPS et le débit du cluster par heure, jour, semaine, mois ou année.
. Sélectionnez image:icon_download.png["flèche bleue vers le bas"] pour télécharger les données de performances.


.Et la suite ?
Utilisez vos metrics de performance du cluster pour déterminer si vous devez modifier vos règles de qualité de service ou effectuer d'autres ajustements de vos charges de travail applicatives afin d'optimiser les performances globales de votre cluster.



[[monitor-storage-unit-performance]]
== Surveiller les performances de l'unité de stockage

Utilisez les indicateurs de performance des unités de stockage pour déterminer l'impact d'applications spécifiques sur la latence, les IOPS et le débit.

.Étapes
. Dans System Manager, sélectionnez *Storage*.
. Sélectionnez l'unité de stockage que vous souhaitez surveiller, puis sélectionnez *Présentation*.
. Sous *Performance*, affichez la latence, les IOPS et le débit de l'unité de stockage par heure, jour, semaine, mois ou année.
. Sélectionnez image:icon_download.png["flèche bleue vers le bas"] pour télécharger les données de performances.


.Et la suite ?
Utilisez les indicateurs de performance de vos unités de stockage pour analyser si vous devez modifier les politiques QoS qui leur sont attribuées afin de réduire la latence et d’optimiser les IOPS et le débit.
