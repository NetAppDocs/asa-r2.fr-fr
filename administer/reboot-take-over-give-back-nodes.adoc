= Redémarrez un nœud sur un système de stockage ASA r2
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Il peut être nécessaire de redémarrer un nœud pour des raisons de maintenance, de dépannage, de mise à jour logicielle ou d'autres raisons administratives. Lorsqu'un nœud est redémarré, son partenaire HA exécute automatiquement une prise de contrôle. Le nœud partenaire effectue ensuite une restitution automatique après que le nœud redémarré soit de nouveau en ligne.

.Étapes
. Dans System Manager, sélectionnez *Cluster > Présentation*.
. Sélectionnez image:icon_kabob.gif["trois points bleus verticaux"] en regard du nœud que vous souhaitez redémarrer, puis sélectionnez *redémarrer*.
. Entrez la raison pour laquelle vous redémarrez le nœud, puis sélectionnez *redémarrer*.
+
La raison pour laquelle vous entrez pour le redémarrage est enregistrée dans le journal d'audit du système.



.Et la suite ?
Pendant le redémarrage du nœud, son partenaire HA prend le relais afin qu'il n'y ait aucune interruption du service de données. Une fois le redémarrage terminé, le partenaire HA effectue une restitution.
